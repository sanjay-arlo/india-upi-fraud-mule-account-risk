# Optional Python Layer

Baseline workflow: **Excel → SQL → Power BI → Decision**.

Use Pandas + NumPy when EDA, anomaly detection, signal relationships, feature engineering or automation improves the investigation workflow.

Suggested use here:
- Pandas: case-level signal profiling and fraud-pattern analysis.
- NumPy: risk-threshold sensitivity and anomaly scoring checks.

Python is optional; SQL and Power BI remain the governed analytical layers.
